# Regex FSM — Звіт про реалізацію

## Опис

Реалізація спрощеного рушія регулярних виразів на основі **скінченного автомата (FSM)**. Підтримує базові конструкції: літерали, `.`, `*`, `+`.

---

## Пояснення імплементації

### Архітектура

Програма будує граф станів із регулярного виразу, а потім перевіряє рядок, проходячи по цьому графу.

### Стани (`State`)

| Клас | Призначення |
|---|---|
| `StartState` | Початковий стан автомата |
| `TerminationState` | Кінцевий стан — означає успішне розпізнавання |
| `AsciiState` | Відповідає конкретному символу (літера або цифра) |
| `DotState` | Відповідає будь-якому одному символу (`.`) |
| `StarState` | Нуль або більше повторень попереднього стану (`*`) |
| `PlusState` | Одне або більше повторень попереднього стану (`+`) |

### Побудова автомата (`RegexFSM.__init__`)

- Ітерується по символах регулярного виразу
- Для `*` і `+` — модифікує вже доданий стан, додаючи петлю (`self-loop`) для повторень
- Для решти символів — створює новий стан і додає його як наступний
- В кінці додає `TerminationState`

### Перевірка рядка (`RegexFSM.check_string`)

Використовує **NFA-підхід** (недетермінований автомат):
- Підтримує множину **поточних активних станів** одночасно
- На кожному символі переходить до всіх можливих наступних станів
- Рядок прийнятий, якщо після обробки всіх символів хоча б один поточний стан — `TerminationState`

---

## Інструкції до запуску

### Вимоги

- Python **3.10+** (використовується `match`-оператор)

### Запуск

```bash
python regex.py
```

### Використання у власному коді

```python
from regex import RegexFSM

pattern = RegexFSM("a*b+c")
result = pattern.check_string("bbbbc")  # True або False
```

---

## Підтримувані конструкції

| Символ | Значення |
|---|---|
| `a`–`z`, `0`–`9` | Конкретний ASCII-символ |
| `.` | Будь-який один символ |
| `*` | 0 або більше повторень попереднього |
| `+` | 1 або більше повторень попереднього |

> **Не підтримується:** `?`, `{n,m}`, `[]`, `()`, `\d`, `\w` тощо.

---

## Приклади запуску

Патерн: `a*4.+hi`  
Читається як: «нуль або більше `a`, потім `4`, потім будь-який символ, потім один або більше будь-яких символів, потім `hi`»

```
$ python regex.py

True    # "aaaaaa4uhi"      — кілька 'a', потім '4', один символ, 'hi'
True    # "4uhi"            — нуль 'a', '4', один символ, 'hi'
False   # "meow"            — не відповідає патерну
True    # "aaa4ubfcdgjschhi"— кілька 'a', '4', багато символів, 'hi'
True    # "4ubfcdgjschi"    — нуль 'a', '4', багато символів, 'hi'
```

### Додаткові приклади

```python
RegexFSM(".*").check_string("anything123")   # True  — будь-який рядок
RegexFSM("ab+c").check_string("ac")          # False — 'b' обов'язковий
RegexFSM("ab+c").check_string("abbc")        # True
RegexFSM("a*b").check_string("b")            # True  — нуль 'a'
RegexFSM("a*b").check_string("aaab")         # True
RegexFSM("a*b").check_string("aaa")          # False — немає 'b'
```
